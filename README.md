# AI Ankipedia

**AI Ankipedia** is a powerful Anki add-on that brings instant, AI-powered definitions and explanations directly into your review sessions. Simply select any text on your card, and a popup will appear with a concise explanation generated by your favorite AI model (Gemini, OpenAI, etc.).

## ✨ Features

-   **Instant Definitions**: Select any text (up to 6 words) in the Reviewer to trigger a popup.
-   **AI-Powered**: Connects to Google Gemini, OpenAI, or local LLMs (via Ollama) to generate context-aware explanations.
-   **Rich Formatting**: Supports Markdown rendering (headers, bold, lists) for readable explanations.
-   **History & Saving**: Save interesting definitions to a local history for later review.
-   **Anki Integrated**: Injected directly into the Reviewer webview for a seamless experience.

## 📥 Installation

1.  Download the latest `AI Ankipedia.ankiaddon` file from the [Releases](../../releases) page.
2.  Open Anki and go to **Tools** > **Add-ons**.
3.  Click **Install from file...**.
4.  Select the downloaded file.
5.  Restart Anki.

## ⚙️ Configuration

1.  After installation, go to **Tools** > **Add-ons**.
2.  Select **AI Ankipedia** and click **Config**.
3.  Add your API Key to the `models` section in the JSON configuration.

**Example Configuration:**
```json
{
  "models": [
    {
      "id": "gemini",
      "name": "Gemini Flash",
      "endpoint": "https://generativelanguage.googleapis.com/v1beta/openai/chat/completions",
      "modelName": "gemini-2.0-flash",
      "apiKey": "YOUR_API_KEY_HERE"
    }
  ]
}
```

## 🛠️ Development

To modify this add-on or build it from source:

1.  Clone this repository.
2.  Make your changes to the python (`__init__.py`) or web assets (`web_assets/`).
3.  Run the build script to generate the package:
    ```bash
    python build.py
    ```
4.  Install the generated `.ankiaddon` file in Anki to test.
